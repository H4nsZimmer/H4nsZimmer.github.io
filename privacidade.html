Política de privacidade do Sistema de Ponto

Última atualização: 16 de novembro de 2026

O Sistema de Ponto é um software de uso interno da WM Service, instalado num computador da própria empresa, para o controle de jornada dos seus funcionários. Esta política explica como o sistema trata os dados, em especial os dados de contas Google.

1. Dados do Google que o sistema acessa

O sistema usa uma única permissão do Google: acesso aos arquivos do Google Drive criados pelo próprio sistema (escopo drive.file). Com ela, o sistema cria a pasta "Backups do Sistema de Ponto" no Google Drive da conta da empresa que autorizou o acesso, envia para lá os arquivos de backup e apaga os backups antigos que ele mesmo criou. O sistema não lê, não lista e não altera nenhum outro arquivo do Google Drive, e não acessa e-mails, contatos, agenda nem outros dados da conta Google.

2. Como esses dados são usados

O acesso ao Google Drive serve exclusivamente para guardar cópias de segurança do próprio Sistema de Ponto. Os arquivos de backup são criptografados (AES-256) no computador da empresa antes do envio, com uma senha que só a empresa conhece; o Google armazena os arquivos, mas não consegue ler o seu conteúdo.

3. Armazenamento e compartilhamento

A autorização do Google fica guardada apenas no computador da empresa onde o sistema está instalado. Nenhum dado obtido das APIs do Google é vendido, compartilhado com terceiros, usado para publicidade ou transferido para qualquer outro lugar além do próprio Google Drive da empresa.

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado. (The use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.)

4. Dados dos funcionários

Os dados do controle de ponto (cadastro, marcações e dados biométricos, quando autorizados pelo funcionário) ficam no computador da empresa e nos seus backups criptografados, tratados conforme a Lei Geral de Proteção de Dados (LGPD) e as regras internas da WM Service.

5. Como revogar o acesso

O acesso ao Google Drive pode ser removido a qualquer momento pelo painel do sistema (Configurações → Backup → Desconectar) ou pela própria conta Google, em myaccount.google.com/permissions. Os arquivos já enviados continuam no Google Drive da empresa até serem apagados.
